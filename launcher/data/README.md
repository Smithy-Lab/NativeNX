# The launcher's sounds and button pictures

Both by Kenney (www.kenney.nl), CC0 (public domain): free to use, credit appreciated. Unmodified; the sounds renamed by
the role the launcher gives them.

- `sounds/`: from Kenney's *Interface Sounds* 1.0 (`LICENSE.txt`), as packaged in https://github.com/Calinou/kenney-interface-sounds:
  move = tick_002, bump = click_005, confirm = select_002, back = back_002, open = open_002, close = close_002,
  launch = maximize_009, toggle = toggle_004, error = error_008.
- `prompts/`: from Kenney's *Input Prompts* 1.1 (`LICENSE.txt`, the 128-pixel "Double" set), as packaged in
  https://github.com/tanuki-billie/kenney-input-prompts: controllers and buttons for Xbox, PlayStation, Nintendo Switch,
  Steam Deck and the keyboard.

- `nativenx-logo.png`, `nativenx-icon.png`: the NativeNX logo (the project's own), cleaned to a transparent background, and
  the app icon made from it on a dark rounded square.
